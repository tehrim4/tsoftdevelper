# TSoftDevelper Premium Portfolio

Production-oriented React + Vite portfolio implementation based on the supplied brief and visual references.

## Stack
- React + Vite
- JavaScript only
- Pure CSS
- Framer Motion
- React Router
- Lucide React

## Run
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

The supplied first reference/logo is included at `public/assets/tsoftdevelper-logo.jpeg`.

The implementation deliberately avoids invented statistics, clients, testimonials, awards, phone numbers, GitHub URLs, or LinkedIn URLs. Where the brief did not provide a value, the UI is designed around the omission.
